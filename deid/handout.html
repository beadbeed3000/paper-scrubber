Takes the student out of an IEP or eval, so you can use AI safely.

As a program (Mac or Windows) github.com/beadbeed3000/
paper-scrubber/releases/latest

Program, first time only: on a Mac, go to System Settings → Privacy & Security → Open Anyway. On Windows, click More info → Run anyway.

How to use it

  1. 1Drop in the IEP or eval (Word, PDF or a scan).
  2. 2Wait about 2 minutes.
  3. 3Read it over, then copy it into the AI.

Ways to use it

  • Summarize a long eval report
  • Check that IEP goals are measurable
  • Compare the services to the eval's recommendations
  • Write a plain-language summary for parents
  • Get ready for an ARC meeting
One rule: always read it before you paste it.
It catches most details, not every one.
